# Stopwatch

Секундомер на React + Vite по макетам Figma (файл Vibecoding, страница Final Design):
`Desktop_Timer_1` (46:182) и `Mobile_Timer_1` (46:192).

## Запуск

Проект использует Node 22 (см. `.nvmrc`):

```bash
nvm use
npm install
npm run dev
```

## Скрипты

- `npm run dev` — сервер разработки
- `npm run build` — сборка в `dist/`
- `npm run preview` — просмотр сборки
- `npm run lint` — проверка oxlint

## Структура

- `src/components/Stopwatch.jsx` — карточка секундомера (Start/Pause, Clear)
- `src/components/SettingsButton.jsx` — круглая кнопка настроек
- `src/components/BackgroundPicker.jsx` — попап выбора фона (Settings_Images)
- `src/components/ScrollArea.jsx` — прокручиваемая область с кастомным скроллбаром (Scroll)
- `src/data/backgrounds.js` — список фонов (см. раздел ниже)
- `src/hooks/useStopwatch.js` — логика и формат времени `HH:MM:SS`
- `src/index.css` — токены из переменных Figma
- `src/assets/backgrounds/` — фоновые изображения
- `src/assets/` — иконки, экспортированные из Figma

## Фоновые изображения

Всё управление фонами — в двух местах:

| Что | Где |
|---|---|
| Файлы изображений | папка `src/assets/backgrounds/` |
| Список и порядок | массив `backgroundList` в `src/data/backgrounds.js` |

Список выглядит так:

```js
const backgroundList = [
  { file: 'clouds.png', label: 'Pastel clouds' },
  { file: 'flowers.png', label: 'Flower field' },
  { file: 'violet.png', label: 'Violet abstract' },
]
```

- `file` — точное имя файла из папки `src/assets/backgrounds/` (с расширением).
- `label` — короткое название; его не видно на экране, но его зачитывают
  программы экранного доступа.

Маленькие превью для попапа создаются автоматически — делать их вручную не нужно.
Полноразмерные фоны при сборке автоматически пережимаются в WebP (качество 82),
исходные файлы в папке не меняются.

### Добавить фон

1. Положите изображение в `src/assets/backgrounds/`.
   Форматы: `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`.
   Имя — латиницей, без пробелов, например `sunset-sea.jpg`.
   Рекомендуемый размер — не меньше 1672 × 941 (как у текущих фонов).
2. Добавьте строку в `backgroundList`:
   ```js
   { file: 'sunset-sea.jpg', label: 'Sunset sea' },
   ```
3. Сохраните файл — фон появится в попапе.

### Удалить фон

1. Удалите его строку из `backgroundList`.
2. Удалите файл из `src/assets/backgrounds/`, чтобы он не попадал в сборку.

### Заменить изображение

- **Оставить то же место в списке:** замените файл в папке новым,
  сохранив **то же имя файла**. Менять `backgrounds.js` не нужно.
- **Новое имя файла:** положите новый файл, поменяйте `file` в строке
  и удалите старый файл.

### Изменить порядок

Переставьте строки в `backgroundList`: попап показывает фоны сверху вниз
(слева направо по рядам). **Первая строка — фон по умолчанию.**

### Если что-то пошло не так

- Опечатка в имени файла не ломает приложение: такая строка пропускается,
  а в консоли браузера появляется предупреждение
  `[backgrounds] "имя" was not found in src/assets/backgrounds/`.
- Если удалить фон, который пользователь выбрал ранее, приложение
  автоматически покажет первый фон из списка.
- Если фонов больше, чем помещается в попап, появляется прокрутка —
  ничего настраивать не нужно.
